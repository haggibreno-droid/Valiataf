# Valiataf · LATAF

Plataforma demonstrativa para apoiar o registro e o acompanhamento longitudinal de feridas.

## Objetivo
Construir um protótipo funcional para validação de fluxos com a LATAF, antes de qualquer uso institucional ou com dados reais.

## Tecnologias
- React + Vite + TypeScript
- Lucide React
- CSS responsivo

## Executar localmente
```bash
npm install
npm run dev
```

## Segurança
Este repositório contém apenas um protótipo. Não inserir dados pessoais, identificadores ou fotografias de pacientes reais. A implantação clínica depende de aprovação institucional, avaliação de segurança, governança de dados e validação dos formulários pela equipe responsável.
